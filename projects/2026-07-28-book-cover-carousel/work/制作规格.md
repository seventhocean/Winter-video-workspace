# 制作规格

## 输入

- 主题：图书讲解类视频开头的书封快速轮转
- 素材：6 张项目内自制演示书封
- 数据入口：`work/books.json`
- 提示词入口：`work/Codex提示词模板.md`
- 原始口播：本阶段无
- 交付日期目录：本阶段仅保留工程预览，暂不正式交付

## 成片

- 平台：抖音
- 画幅：1080×1920
- 目标时长：5.2 秒
- 帧率：30fps
- 风格 Profile：`clinical-tech`
- 视觉参考：用户提供的 4 秒竖屏书封轮播视频
- 参考状态：实验性风格参考
- 复现策略：只提取“固定窗口内书封带向上滚动、节奏加速、机械点击锁定”的运动与声音语言，不复制原视频素材、边框和书单
- 声音：逐页短促的齿轮“嘎达”声，最终停留收束声
- 字幕：无
- BGM：无

## 工作流

```text
替换封面图片
→ 更新书单数据
→ 设置目标书
→ 设置翻转时间点
→ 逐页触发音效
→ 最终停留并收束
```

## 第二版验收

- 书封在固定竖直窗口内由下向上轮转，始终保持正常方向。
- 相邻书封在窗口边缘短暂同时可见，形成连续书封带。
- 整条书封带从启动到停止保持连续位移，中间不逐张停靠。
- 同一组书封默认循环经过 3 轮，再继续转到目标书；循环次数由数据参数控制。
- 速度曲线包含自然启动、中段高速和末段惯性减速，运动中带有轻微动态模糊。
- 转动区间持续铺设低频轮盘机械底声；齿轮“嘎达”声作为随转速变化的棘轮节拍，不与单张书封机械绑定。
- 最后一张主推书稳定停留至少 1 秒。
- 替换 `work/books.json` 中的图片路径和书名后，不需要修改动画组件。
- 视频包含 H.264 画面和音频流，无意外黑帧。
