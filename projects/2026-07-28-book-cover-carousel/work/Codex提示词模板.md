# Codex 提示词模板｜通用纵向轮盘视频

这是一份“只填写内容”的固定模板。复制整段提示词后，只修改 `【本期内容】` 区域。

## 可直接复制的提示词

```text
请在当前 Winter 视频集中工作区中，使用已经验证过的纵向轮盘工作流，为我生成一段竖屏轮盘视频。

【本期内容｜只修改这里】

<在这里填写文本列表，或者说明使用当前项目素材目录中的哪些图片>

【本期内容结束】

内容识别规则：
1. 如果“本期内容”是多行文本，每个非空行视为一个独立项目，为每个项目生成一张统一风格的文字卡片。
2. 如果“本期内容”指定了当前项目中的图片目录或图片文件，读取其中全部 PNG、JPG、JPEG、WEBP 或 SVG 图片，按文件名自然排序，每张图片作为一个项目。
3. 如果同时提供图片和标题，将对应图片与标题组合成统一尺寸的卡片。
4. 内容列表的最后一项默认是最终停留项，不再向我询问目标项。
5. 如果没有指定项目名，根据当天日期和内容自动生成只含小写字母、数字及连字符的项目名。

固定成片规格：
- 画幅：1080×1920。
- 帧率：30fps。
- 时长：约 5.2 秒。
- 默认循环：同一组内容完整经过 3 轮，再继续转到最后一项。
- 不添加旁白和背景音乐。

固定视觉结构：
1. 把所有内容做成尺寸一致的卡片，并首尾相接为一条可循环的竖直内容带。
2. 内容带位于固定轮盘窗口内，由下向上连续滚动；窗口边缘可以看到相邻卡片。
3. 文字和图片始终保持正常方向，不能镜像、倒置或使用会翻转文字的三维动画。
4. 使用二维纵向位移、窗口遮罩和轻微缩放；不能逐项停靠、逐格切换或左右飞出。
5. 整段只使用一条连续速度曲线：缓慢启动、中段加速、靠惯性自然减速。
6. 循环过程中不能出现接缝、跳帧、空白或素材突然重置。
7. 高速阶段加入轻微纵向动态模糊，停止后恢复清晰。
8. 最后一项落位时允许轻微回弹，随后保持清晰至少 1 秒。

固定声音设计：
1. 转动全程铺设持续数秒的低频轮盘机械底声。
2. 叠加短促、偏硬质的齿轮“嘎达”声；启动时较疏，中段较密，减速时再次变疏。
3. 齿轮点击是跟随转速的独立棘轮节拍，不与某一张卡片机械绑定。
4. 最后一项停止时触发较低、更稳定的收束声，画面与声音同时锁定。

固定工程要求：
1. 所有新项目只创建在 Winter-video-workspace/projects/。
2. 使用根目录共享依赖，不运行 npm install。
3. 图片使用当前项目内的小型素材，或通过工作区的 link-asset 流程链接。
4. 先建立制作规格、内容数据和 timeline.json，再实现动画。
5. 把内容、最终停留项、循环轮数和时间参数保留为数据入口，不把本期内容写死在动画组件中。
6. 先渲染首、中、尾结构帧，再渲染完整预览。
7. 完成后检查分辨率、帧率、音轨、黑帧、循环接缝、连续运动和最终停留项。
8. 直接完成制作并返回预览视频路径；除非素材不存在或无法读取，否则不要中途向我确认固定参数。
```

## 文本输入示例

只替换提示词中的 `【本期内容】`：

```text
回避型依恋
焦虑型依恋
安全型依恋
混乱型依恋
```

视频默认停在最后一项“混乱型依恋”。如果希望停在“回避型依恋”，把“回避型依恋”移动到列表最后即可。

## 图片输入示例

```text
使用当前项目 public/input/ 目录中的全部图片，按文件名自然排序。
```

视频默认停在排序后的最后一张图片。

## 混合输入示例

```text
ISTJ | public/input/istj.png
ENFP | public/input/enfp.png
INTJ | public/input/intj.png
INFJ | public/input/infj.png
```

## 每期唯一需要修改

只修改 `【本期内容】`。画幅、时长、循环轮数、速度曲线、声音、停止逻辑、工程结构和质量检查均使用固定默认值。
