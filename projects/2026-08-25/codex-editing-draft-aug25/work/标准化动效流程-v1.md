# Winter 口播视频标准化动效流程 v1

这套流程标准化的是“怎么把文章结构翻译成持续生长的视觉舞台”，不是把所有视频做成同一种版式。

## 0. 先识别文章的树状结构

- 主干：这一章共同在讲什么，决定舞台的核心标题与空间骨架。
- 分支：内容从哪一句开始进入第一种方法、第二种方法或新的论点；只有分支变化才整体换舞台。
- 叶节点：同一分支中的步骤、素材、证据和结果；每讲完一个节点就缩小归档，下一节点在下方或旁边继续生长。
- 阶段总结：一个局部流程讲完后，把已经归档的节点重组为一次简短的横向或纵向总结动画。

## 1. 先拆句，不先选组件

每个完整语义句仍要标记开始时间、关键词和动作，但句子只推动当前舞台变化，不默认创建新舞台。连续句属于同一分支时，沿同一空间骨架累积；进入新的分支时才清场。

## 2. 判断句子属于哪一种视觉任务

- 观点或结论：使用粗体大字，关键词先放大进入，再缩小或让位。
- 具体对象：使用能一眼识别的实心象形图，优先放在人物两侧或下方。
- 递进或步骤：使用横向或纵向流程组，按口播顺序逐项点亮。
- 对比：使用左右两组大小、颜色或状态明显不同的元素。
- 操作演示：让录屏或真实素材成为主体，动效只负责指示关键区域。
- 证据或结果：使用截图、数字或局部放大，不再叠加解释性装饰。

## 3. 固定动作语法

1. 重点词以 1.15–1.30 倍进入。
2. 0.3–0.5 秒内回落到正常尺寸。
3. 下一句仍属于同一分支时，上一重点缩小、移位并归档保留；只有分支结束时才整体退出。
4. 象形图必须与本句名词或动作直接对应。
5. 一句话至少推动一次可见变化，但不要求新增舞台，也不要求删除上一句话。

## 4. 固定安全规则

- 人脸、眼睛、嘴、手势和字幕区优先级最高。
- 可以轻压头发，不覆盖五官。
- 5.8 英寸画布的上下黑框始终保持空白。
- 手机端主关键词使用粗体大字号；辅助文字不得依赖细线或微型英文才能看懂。
- 线条只在关系本身需要时使用，并保持短、粗、少。

## 5. 每期单独配置视觉皮肤

每期只需定义主色、辅色、黑白关系、圆角尺度和图形质感。本期配置为：白色原片背景、黑色粗体、高饱和蓝色主强调、青色次强调。下一期可以更换颜色与图形质感，但继续沿用上述语义映射和动作节奏。

## 6. 验收闸门

1. 先输出 3 张结构帧，检查字号、占位和人脸避让。
2. 再输出 10–15 秒动态样片，检查一句一变化和动作完成时机。
3. 用户确认视觉语法后，才扩展全片。
4. 全片完成后检查黑框、五官、字幕、音频、帧率、分辨率与代表帧。
