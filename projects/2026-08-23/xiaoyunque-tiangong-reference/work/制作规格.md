# 制作规格

## 输入

- 主题：小云雀商单开场——云顶天宫热门案例包装
- 原始口播：后续单独录制并在总工程中对齐
- 逐字稿：最近这种云顶天宫视频特别火。我把这种视频做成了一个 Skill，只要输入想要的场景和时长，它就能自动生成关键帧和视频。先看一下我用它生成的效果。
- 素材目录：`/Users/winter/Movies/Videos/8月23小云雀商单/示例视频`
- 交付日期目录：`/Users/winter/Movies/Videos/8月23小云雀商单/edit`

## 成片

- 平台：抖音
- 画幅：16:9 横屏，1920×1080 审片交付

- BGM：无

## 舞台级分镜

| 时间 | 场景模式 | 主视觉 | 状态变化 |
|---|---|---|---|
| 0–5 秒 | 素材与全屏视觉 | 带暗金边框的参考视频窗口 | 播放进度推进至完成 |
| 5–7 秒 | 复杂解释 | 参考定格＋三个巨物感特征 | 巨型建筑、极小人物、云海纵深依次进入 |
| 7–9.5 秒 | 复杂解释 | 场景与时长 → 关键帧 → 视频 | 三个步骤依次点亮并连接 |
| 9.5–10.4 秒 | 素材与全屏视觉 | “我的生成效果”交接标题 | 米白色擦除转场，衔接下一段自有示例 |

## 舞台计划

先建立 `timeline.json`，再进入完整渲染。6 秒以上纯动画章节必须填写 `motionBeats`。

- 每个 scene 先填写一个场景模式：人物口播、复杂解释、实操与录屏或素材与全屏视觉；`layoutProfile`、构图和拓扑由 Skill 内部映射。
- 人物口播重点句默认使用递进式语义舞台，至少包含一个静态重点和一个动态补充；单句和连续语义由 Skill 内部选择具体布局。
- 语义元素按口播需要添加文字、图标、图片、指标、关系图、步骤、真实素材或状态变化，不为了丰富而堆装饰。
- 复杂系统关系才进入高密度解释舞台；PPT / 录屏始终优先使用保护模式。
- `sourceFile` 通过根目录 `npm run link-asset` 链接到项目 `public/`。
- HyperFrames 先输出无声透明层或无声全屏段，再作为 `hyperframes-overlay` 接入同一时间轴。
