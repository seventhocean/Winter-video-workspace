# DeepSeek Harness 口播动效制作规格

- 项目日期：2026-08-14
- 成片画幅：4:3，2880×2160，30fps
- 交付形式：开头、结尾分别输出，不拼接中段
- 原片策略：保留现有剪辑和音频，不加字幕、不改变色彩、不裁切人物
- 视觉策略：编辑式信息设计为主，DeepSeek 蓝青色作为识别色；拒绝大面板和卡片套卡片
- 安全区：人物面部与手部优先；主要动效位于右上和右侧中部；底部预留后续字幕空间
- 同步策略：依据 ElevenLabs Scribe 逐词时间戳对齐关键词，动效略早 2–4 帧预备，在语义落点完成

## 开头语义动效

1. DeepSeek 拥有 Agent：Agent 核心和节点组装。
2. 一天不到、7 万多 Star：`<24H` 与 `70K+` 数字增长、星标爆发。
3. 肥鲸鱼拥有专武：鲸鱼轮廓出现，Harness 环完成装备。
4. 到底怎么样、试一下：PLAN / TOOL / ACT 连线，最后落到 `试一下`。

## 结尾语义动效

1. 专武回扣：复用鲸鱼装备 Harness 的视觉记忆。
2. 速度快、缓存命中高：速度轨迹和缓存方块依次点亮。
3. 部署麻烦、不能开箱即用、门槛较高：阶梯路径逐级上升；说到后续优化时出现平滑捷径。
4. 插件市场值得期待：插件节点围绕 Harness 核心连续生长。
5. 评论互动：三个待定义插件槽位和问题句收尾。

## 舞台计划

先建立 `timeline.json`，再进入完整渲染。6 秒以上纯动画章节必须填写 `motionBeats`。

- 每个 scene 先填写一个场景模式：人物口播、复杂解释、实操与录屏或素材与全屏视觉；`layoutProfile`、构图和拓扑由 Skill 内部映射。
- 人物口播重点句默认使用递进式语义舞台，至少包含一个静态重点和一个动态补充；单句和连续语义由 Skill 内部选择具体布局。
- 语义元素按口播需要添加文字、图标、图片、指标、关系图、步骤、真实素材或状态变化，不为了丰富而堆装饰。
- 复杂系统关系才进入高密度解释舞台；PPT / 录屏始终优先使用保护模式。
- `sourceFile` 通过根目录 `npm run link-asset` 链接到项目 `public/`。
- HyperFrames 先输出无声透明层或无声全屏段，再作为 `hyperframes-overlay` 接入同一时间轴。
