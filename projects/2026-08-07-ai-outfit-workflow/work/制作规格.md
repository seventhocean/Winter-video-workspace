# AI 换装视频工作流拆解·制作规格

- 逻辑画布：1080×1440，3:4，30fps；正式成片等比 2× 渲染为 2160×2880，约 50.63 秒。
- 主音轨：`口播精剪版.mov`。开头先用爆款视频首帧承接“先看这个视频”，随后从头完整播放案例；结果段也完整播放后再恢复口播。
- 主风格：`editorial-neutral`，米白纸张、炭黑、淡紫强调；不使用 clinical-tech 蓝底卡片系统。
- 字幕：中文单行短句，最后一层合成，底部安全区居中。

## 镜头结构

1. 0.00–8.40：左侧爆款案例，右侧 Winter PIP；前 1.2 秒冻结案例首帧，随后从第 1 帧完整播放约 7.2 秒。
2. 8.40–14.87：全屏人脸；三张真实点赞截图逐张进入，最后落到“两个提示词”。
3. 14.87–23.77：整屏第一步动画＋右下 PIP；真实提示词一录屏、角色、衣服、拼贴图依次推进。
4. 23.77–30.20：整屏第二步动画＋右下 PIP；真实提示词二录屏、第一张图、Seedance 2.0、换装视频形成路径。
5. 30.20–32.53：全屏人脸；“2 分钟”与生成进度完成。
6. 32.53–40.60：左侧最终换装成片，右下 PIP；结果视频从头完整播放约 8.07 秒。
7. 40.60–50.63：无人物 PIP 的全屏动画，解释“换角色 / 换衣服 → 只改对应特征 → 两个提示词 → 整套工作流 → 收藏”。

## 音频

- 爆款案例从正式播放开始保留完整原声，首帧冻结阶段只保留“先看这个视频”的口播。
- 最终换装成片 BGM 以 12% 音量铺底，始终服从口播。
- 所有素材视频本体静音，避免重复音轨。

## 验收重点

- “第一步”“第二个提示词”“等两分钟”“看一下效果”必须落在对应画面切换点。
- 三张爆款截图必须真实出现，不用伪造数字替代证据。
- 两个提示词段不能只剩大字或单卡片，必须同时有真实录屏、路径和结果状态。
- 人脸 PIP、文字、真实 UI 和字幕互不遮挡。
